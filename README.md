A vintage travel poster for **LUMARIS**, a floating archipelago above a sea of clouds — a place that does not exist. One great floating isle with its lighthouse, houses and waterfalls, a low golden sun, and an airship arriving from the lowlands. Ever-spring, fare from 12 crowns.

## Run

```sh
python3 main.py
```

Writes one 1024x1024 PNG to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set). Pure Python standard library only — the program draws every pixel itself, including its own PNG writer and its own 5x7 bitmap font. No network, no randomness, deterministic output.
